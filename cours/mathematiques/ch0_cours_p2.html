Module, Argument & Formes

Comment mesurer la « taille » d'un complexe et son orientation ? Cette partie introduit le module, l'argument, et les formes trigonométrique et exponentielle — outils essentiels pour les calculs avancés.

01
Définition

Le module d'un nombre complexe

Dans le plan complexe, un nombre z = a + ib est représenté par un point M(a, b). On peut naturellement mesurer la distance entre l'origine O et ce point M. Cette distance s'appelle le module de z.

Définition du module
|z| = √(a² + b²)
Le module de z = a + ib est la distance OM dans le plan complexe

Le module se note |z| (comme la valeur absolue) ou parfois r. C'est toujours un réel positif ou nul. Contrairement aux apparences, ce n'est pas un complexe.

Interprétation géométrique

Le module |z| est la longueur du segment OM dans le plan complexe. C'est l'analogue de la valeur absolue |x| sur la droite réelle, qui mesure la distance entre x et 0.

Propriétés immédiates

  • |z| ≥ 0 pour tout complexe z — un module est toujours positif ou nul.
  • |z| = 0 ⟺ z = 0 — seul le complexe nul a un module nul.
  • |z| = |-z| — l'opposé a le même module.
  • Si z est réel, alors |z| est la valeur absolue classique.

Module de quelques cas simples

  • Réel pur : z = a, alors |z| = |a| (valeur absolue classique).
  • Imaginaire pur : z = ib, alors |z| = |b|.
  • Cas général : z = a + ib, on applique la formule |z| = √(a² + b²).
Exemples de calcul

z = 3 + 4i : |z| = √(3² + 4²) = √(9 + 16) = √25 = 5

z = -5 : |z| = √((-5)² + 0²) = √25 = 5

z = 2i : |z| = √(0² + 2²) = √4 = 2

z = 1 - i : |z| = √(1² + (-1)²) = √2

Attention

Le module n'est pas la somme des modules des parties. Par exemple, pour z = 3 + 4i, on a |z| = 5, et non 3 + 4 = 7. Il faut bien élever au carré, additionner, puis prendre la racine.

02
Définition

L'argument d'un nombre complexe

Le module mesure la distance. Mais il manque une information : dans quelle direction se trouve le point M ? C'est le rôle de l'argument : l'angle que fait le vecteur OM avec l'axe des réels.

Définition de l'argument
θ = arg(z)
Angle orienté entre l'axe des réels positifs et le vecteur OM

L'argument se mesure en radians, dans le sens direct (sens inverse des aiguilles d'une montre). Il est défini modulo 2π : si θ est un argument de z, alors θ + 2kπ est aussi un argument de z, pour tout entier k.

Argument principal

Pour éviter l'ambiguïté, on choisit souvent l'argument principal, noté Arg(z) (avec majuscule), qui est l'unique argument appartenant à l'intervalle ]-π, π]. C'est celui qu'on affiche par convention.

Comment calculer l'argument ?

Pour z = a + ib ≠ 0, on utilise les relations suivantes, qui découlent directement de la trigonométrie dans le triangle rectangle :

cos(θ) = a / |z|
Le cosinus de l'argument est la partie réelle divisée par le module.
sin(θ) = b / |z|
Le sinus de l'argument est la partie imaginaire divisée par le module.

Connaissant cos(θ) et sin(θ), on identifie l'angle θ à l'aide des valeurs remarquables du cercle trigonométrique.

Arguments remarquables

0
arg(1) = 0
réels positifs
π/2
arg(i) = π/2
imaginaires purs positifs
π
arg(-1) = π
réels négatifs
-π/2
arg(-i) = -π/2
imaginaires purs négatifs
Exemple guidé

Calculer le module et l'argument de z = 1 + i.

Étape 1 — Module : |z| = √(1² + 1²) = √2

Étape 2 — Cos et sin : cos(θ) = 1/√2 = √2/2 et sin(θ) = 1/√2 = √2/2

Étape 3 — Identification : l'angle dont le cosinus et le sinus valent √2/2 est π/4.

Conclusion : |z| = √2 et arg(z) = π/4.

Attention

L'argument n'est pas défini pour z = 0 : le point O n'a pas de direction privilégiée. On dit souvent que arg(0) est indéterminé.

03
Écriture

Forme trigonométrique

Connaissant le module r = |z| et un argument θ = arg(z), on peut réécrire z sous une nouvelle forme, dite trigonométrique.

Forme trigonométrique
z = r(cos θ + i sin θ)
avec r = |z| > 0 et θ = arg(z)

Cette écriture met en évidence les deux informations géométriques : r (la distance) et θ (l'angle). Elle est équivalente à la forme algébrique z = a + ib, avec les relations a = r cos θ et b = r sin θ.

Passer de la forme algébrique à la forme trigonométrique

1
Calculer le module

r = √(a² + b²)

2
Factoriser par r

z = r(a/r + i·b/r)

3
Identifier cos θ et sin θ

cos θ = a/r et sin θ = b/r

4
Déterminer θ

À l'aide des valeurs remarquables du cercle trigonométrique.

🎓 Exemple complet

Écrire z = 1 + i sous forme trigonométrique.

Étape 1 : r = |z| = √(1² + 1²) = √2

Étape 2 : z = √2(1/√2 + i·1/√2) = √2(√2/2 + i·√2/2)

Étape 3 : On identifie cos θ = √2/2 et sin θ = √2/2, donc θ = π/4.

Résultat : z = √2(cos(π/4) + i sin(π/4))

Deuxième exemple

Écrire z = -1 + i√3 sous forme trigonométrique.

Étape 1 : r = √((-1)² + (√3)²) = √(1 + 3) = √4 = 2

Étape 2 : z = 2(-1/2 + i·√3/2)

Étape 3 : On identifie cos θ = -1/2 et sin θ = √3/2, donc θ = 2π/3.

Résultat : z = 2(cos(2π/3) + i sin(2π/3))

04
Écriture

Forme exponentielle

Il existe une troisième forme, encore plus compacte : la forme exponentielle. Elle repose sur la formule d'Euler, qui relie l'exponentielle complexe aux fonctions trigonométriques.

Formule d'Euler
e^(iθ) = cos θ + i sin θ
pour tout réel θ

En combinant cette formule avec l'écriture trigonométrique z = r(cos θ + i sin θ), on obtient la forme exponentielle :

z = r · e^(iθ)
avec r = |z| et θ = arg(z)

Valeurs remarquables

  • e^(i·0) = 1
  • e^(iπ/2) = i
  • e^(iπ) = -1
  • e^(-iπ/2) = -i
  • e^(2iπ) = 1
L'identité d'Euler

En prenant θ = π dans la formule d'Euler, on obtient e^(iπ) = -1, soit l'identité célèbre :

e^(iπ) + 1 = 0

Cette formule relie cinq constantes fondamentales des mathématiques : e, i, π, 1 et 0.

Exemples d'écriture

Reprenons z = 1 + i : module √2, argument π/4.

Forme trigonométrique : z = √2(cos(π/4) + i sin(π/4))

Forme exponentielle : z = √2 · e^(iπ/4)

Autre exemple : z = -1 a pour module 1 et argument π, donc z = e^(iπ).

05
Propriétés

Propriétés des modules et arguments

Les formes trigonométrique et exponentielle rendent les multiplications et divisions beaucoup plus simples. C'est leur grand avantage.

Modules

|z · z'| = |z| · |z'|
Le module d'un produit est le produit des modules.
|z / z'| = |z| / |z'|
Le module d'un quotient est le quotient des modules (z' ≠ 0).
|zⁿ| = |z|ⁿ
Pour tout entier n.

Arguments

arg(z · z') = arg(z) + arg(z')
Modulo 2π.
arg(z / z') = arg(z) - arg(z')
Modulo 2π (z' ≠ 0).
arg(zⁿ) = n · arg(z)
Modulo 2π, pour tout entier n.
Pourquoi ces règles ?

En écriture exponentielle, une multiplication devient une addition dans l'exposant : r·e^(iθ) × r'·e^(iθ') = (r·r')·e^(i(θ+θ')). Les modules se multiplient et les arguments s'additionnent. C'est toute la puissance de cette écriture.

Formule de Moivre

Une conséquence directe des propriétés d'argument :

Formule de Moivre
(cos θ + i sin θ)ⁿ = cos(nθ) + i sin(nθ)
pour tout entier n et tout réel θ

Sous forme exponentielle, cette formule devient triviale : (e^(iθ))ⁿ = e^(inθ). C'est cette simplicité qui fait la force de l'écriture exponentielle.

Application

Calculer (1 + i)⁸.

Étape 1 — Forme exponentielle : 1 + i = √2 · e^(iπ/4)

Étape 2 — Puissance : (1 + i)⁸ = (√2)⁸ · e^(i·8π/4) = 16 · e^(i·2π)

Étape 3 — Or e^(i·2π) = 1, donc (1 + i)⁸ = 16.

06
Applications

Applications classiques

Voici les trois applications les plus fréquentes des formes trigonométriques et exponentielles en Terminale.

Application 1 — Écrire un complexe sous forme exponentielle

Méthode complète

Exemple : écrire z = -√3 + i sous forme exponentielle.

1. Module : r = √(( -√3)² + 1²) = √(3 + 1) = 2

2. Cos et sin : cos θ = -√3/2 et sin θ = 1/2

3. Identification : ces valeurs correspondent à θ = 5π/6.

4. Résultat : z = 2 · e^(i·5π/6)

Application 2 — Calculer une puissance élevée

Méthode complète

Exemple : calculer (1 + i)¹⁰.

1. Forme exponentielle : 1 + i = √2 · e^(iπ/4)

2. Élever à la puissance : (1 + i)¹⁰ = (√2)¹⁰ · e^(i·10π/4)

3. Simplifier : (√2)¹⁰ = 2⁵ = 32, et 10π/4 = 5π/2.

4. Réduire l'angle modulo 2π : 5π/2 = 2π + π/2, donc e^(i·5π/2) = e^(iπ/2) = i.

5. Résultat : (1 + i)¹⁰ = 32i

Application 3 — Linéariser une puissance de cos ou sin

Les formules d'Euler permettent d'exprimer les puissances de cos θ et sin θ en sommes de cosinus et sinus de multiples angles. Cette technique, appelée linéarisation, sera détaillée dans la Partie 8. Retenons simplement les formules de base :

cos θ = (e^(iθ) + e^(-iθ)) / 2
Formule d'Euler inverse pour le cosinus.
sin θ = (e^(iθ) - e^(-iθ)) / (2i)
Formule d'Euler inverse pour le sinus.
À retenir

La forme exponentielle transforme les multiplications en additions d'arguments et les puissances en multiplications d'arguments. C'est l'outil de calcul par excellence dès que les exposants deviennent grands.

📌 Ce qu'il faut retenir
  • Le module |z| = √(a² + b²) mesure la distance OM dans le plan complexe.
  • L'argument θ = arg(z) est l'angle orienté entre l'axe des réels et le vecteur OM.
  • Forme trigonométrique : z = r(cos θ + i sin θ) avec r = |z|
  • Formule d'Euler : e^(iθ) = cos θ + i sin θ
  • Forme exponentielle : z = r · e^(iθ)
  • |z · z'| = |z| · |z'| et arg(z · z') = arg(z) + arg(z')
  • Formule de Moivre : (cos θ + i sin θ)ⁿ = cos(nθ) + i sin(nθ)
  • Applications : écrire sous forme exponentielle, calculer des puissances élevées, linéariser.
